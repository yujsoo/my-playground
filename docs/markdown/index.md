# Markdown Guide

이 블로그에서 사용하는 마크다운 문법 예시입니다.

## 제목

```md
# H1

## H2

### H3
```

## 텍스트

```md
**굵게** / _기울임_ / ~~취소선~~
```

## 코드

인라인 `코드` 및 블록:

```js
console.log("hello");
```

## 표

| 항목 | 설명 |
| ---- | ---- |
| A    | 내용 |
| B    | 내용 |

## 팁 블록

::: tip
팁 내용
:::

::: warning
주의 내용
:::

::: danger
위험 내용
:::
